### Bug fixes

- What the assistant decides from a reporter's words without the AI, it now decides from the text as GitHub shows it, cleaned as the AI reads it: the words of the search for older issues, the language of its comments while no analysis has named one, the area of the form with its label and its owners, and whether the description of a merged pull request says that it doesn't fix an issue. Before, an HTML comment, an attribute of a tag or a link reference definition counted as words, so that the English instruction of a Markdown template in a comment could make the assistant answer a German report in English, and a second answer of the area in a comment chose its label. The box that keeps the AI out counts as ticked when it is ticked anywhere below its heading, in the text as GitHub stores it or as the page shows it, so that a box that the page doesn't show can't untick it.
