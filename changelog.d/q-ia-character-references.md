### Bug fixes

- The AI no longer reads a character reference of a character that GitHub shows as nothing, such as `&#xE0041;`, `&#x200B;` or `&ZeroWidthSpace;`: GitHub shows such a reference as the character itself, so as nothing, and the reference now goes with the characters, also without its `;`, and the log counts it with them. Code keeps its references, as GitHub shows them there as they are written, such as `auto p = &it;` in fenced code. The titles of issues and discussions lose them as well. The search for older issues, the language of the comments, the area, the box that keeps the AI out of an issue and whether a pull request denies that it fixes an issue read the other references as the characters that GitHub shows, so `doesn&#39;t close #12` denies and `- [&#120;]` ticks the box. A link to an attached file whose address holds such a character or a reference of one, which GitHub shows as a link that leads nowhere, no longer counts as an attachment.
