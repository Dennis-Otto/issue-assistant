### Bug fixes

- A feature request no longer hears of a fix and of a problem that persists. When a pull request closes an issue with the label `enhancement` or the issue type *Feature*, and without the label `bug`, the comment at the merge says that the pull request implemented it, and the comment at the release asks the reporter to update to use it and to write a comment if something is missing; the AI that reads that comment reopens the issue when what it asked for is still missing or doesn't work. Every other issue keeps the words of a fix. Both kinds read alike in all 14 languages, under the same hidden markers, so the sweeps and the digest read old and new comments alike.
