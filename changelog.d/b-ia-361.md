### Bug fixes

- The notes of a release that updates an engine name the engine and its versions, such as "update the Gemini CLI to 0.66.0 (was 0.65.0)", so the pull request that moves your pin says which version of Codex, Gemini, Copilot or the Claude Code action your analyses run from then on. They said only "update the other engines" before, as in 1.10.6, whose entry in the changelog now names the Gemini CLI 0.66.0 and the Codex CLI 0.166.0. The action of Codex and its command line now come in pull requests of their own.
- The FAQ, the README and *How it works* name the fifth workflow, `discussion-assistant.yml`, which answers discussions with the engine where `answer_categories` names categories, as the starter does. The FAQ said that deleting four workflows turns off everything, which left that one answering.

### Added

- *Get started* on the website has a part *Remove the assistant*: the workflows and files to delete, the environment with the engine's secret and the variables, the issues that nothing reminds or closes any more, the setting of GitHub that the set-up cleared, and the notice to reporters.
- The README and the home page show three real first analyses instead of one: a bug in HomeDarts traced into the lines of its code, a feature request in Paperless Sync, and an answer in the reporter's Chinese with a summary in English for the maintainer.
