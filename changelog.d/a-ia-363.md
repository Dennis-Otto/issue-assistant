### Features

- A repository that starts with the assistant can now have the issues that were already open analyzed too. A maintainer runs `issue-assistant.yml` by hand with the new task `backlog` and `0` as the issue: it takes the oldest open issues without a first analysis, up to `backlog_per_run` of `[engine]` in `config.toml`, 20 by default, and leaves out those that a new issue would not have had analyzed either, such as a maintainer's own or a muted one. As every run by hand, it starts as a dry run, and the summary shows for each issue its labels, a possible duplicate and the missing information. With the dry run off, it sets the labels alone and posts no comment on the old issues, unless you tick the new input `comment`. The summary names the last issue that it took, after which the next run goes on. The runs on the backlog count toward no daily limit, and only the roles `admin` and `maintain` start them. Install the templates of this release to get the task and the new job `backlog` of `issue-assistant.yml`; [Runs by hand](https://github.com/Dennis-Otto/issue-assistant/blob/main/docs/features/runs-by-hand.md#the-backlog) shows it.
