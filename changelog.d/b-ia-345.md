### Bug fixes

- A comment in German now links the German notice to reporters: the footer of an analysis, a follow-up and a duplicate notice links the first file of `[transparency] files` that ends in `.de.md`, such as `SUPPORT.de.md`, at its heading *Was mit deinem Issue geschieht*. Before, every comment linked the first file, mostly the English one. A comment in English, or in a language without a notice of its own, links the first file as before.
- The AI's text no longer makes headings in a comment by underlining a line with `===` or `---`, or with `#` inside a quote or a list item: the cleaning now escapes such a line and removes such marks, or escapes them deeper in a list, as it did with `#` at the start of a line.
- The error of a failed check of the network block now links the page *Troubleshooting* of the website at an address that exists. Before, it led to a page that wasn't found.
- The workflow `issue-lifecycle.yml` that `install` writes no longer waits for a workflow named *Release integration*, which no repository has any more; it starts at the end of the workflow *Release*, as before.
