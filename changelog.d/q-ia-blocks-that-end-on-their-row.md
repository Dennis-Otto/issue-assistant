### Bug fixes

- The AI no longer reads what GitHub hides below an instruction or a comment that ends on its own row, such as `<?>`, `<!-->` or `<!--->`. GitHub reads the next row as Markdown again and hides there, as anywhere else, the words after the language of a fence, the cells that a table drops, the titles of links and images, link reference definitions and the source of a drawing; the assistant took such a row for an HTML block that runs on, and kept those words. It now leaves them out of the issue, its comments, the excerpts and the attachments, also after an inline `<!-->` before a drawing, and the search for older issues, the language of the comments, the area and whether a pull request denies that it fixes an issue read them the same way. On the safe side, a row below `<!-->` or `<!--->` that looks like a definition or a footnote goes, as it does below other HTML.
