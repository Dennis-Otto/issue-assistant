### Bug fixes

- The AI no longer reads the rest of a part that GitHub hides behind a comment that ends at a `--!>` or a `--->`. GitHub ends a comment there, but still reads what follows as HTML up to the next `-->`, so a tag after such an end hides what its value or its content holds, such as `<!-- a --!> <a title="-->`, and often the rest of the text; the assistant read the comment up to that `-->` and kept everything after it. Where a tag follows such an end, it now leaves the rest of the text out of the issue, its comments, discussions, the excerpts and the attachments, and the search for older issues, the language, the area and whether a pull request denies that it fixes an issue read it the same way. On the safe side, the AI also misses some text that GitHub still shows there, such as the words after a `<video>` that holds the `-->`.
