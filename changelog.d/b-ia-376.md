### Bug fixes

- `check` and `install` read the issue forms and the workflows right on a computer without PyYAML, where they read YAML with `yq`: a label such as `Gerät` stays `Gerät` on Windows, where it turned into `GerÃ¤t` before, and one such as `Ámbito` no longer ends the step with a `TypeError`. Output of `yq` that is no UTF-8 is now named as a file that isn't valid YAML.
- A pull request that fixes more than ten issues now gets `fixed-in-next-release` onto each of them, up to a hundred, and a release closes an issue only once it ships every fix of up to a hundred pull requests that name it; before, the eleventh and every later one went unnoticed. Where more than a hundred are named, a notice in the summary of the sweep says which part was not read.
- *Get started* now creates the branch policy of the environment by hand for the default branch of the repository, as `install --setup` does, instead of a fixed `main`: a repository on `master` or `develop` got an environment that its runs could not use.
