### Bug fixes

- A new code scanning alert fails one run of the Findings workflow again, not two or three. The scans of a push end close together, so their Findings runs overlap, and a run that read the record of the reported alerts before the run ahead kept its new one failed for the same alert once more. Now a run looks for a newer record once its turn has come, and when one is there, it names the alerts that its own record lacks with a warning and leaves them to that record: the next run fails for any alert that the newer record doesn't hold.
