### Features

- `ISSUE_ASSISTANT_FIXTURE` may now name a file with a discussion, so you can try the first answer to a question in Discussions on one that exists nowhere, as you could with an issue. Write the discussion with its comments and their replies as GitHub's GraphQL API gives it, under the key `discussion`; `context` and `apply` with the task `discussion-answer` then read it instead of one on GitHub, and write nothing. `apply` answers it as a run by hand does, whatever its category, but never when it is closed or locked.
- Each release of the workflow of the discussions has run before you get it: every pull request of the issue assistant that changes it now runs its jobs on a discussion of a file, as a dry run, as it did for the workflow of the issues. A broken step, permission or condition shows there, not as a missing answer in your repository.
