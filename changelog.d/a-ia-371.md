### Bug fixes

- `check` now names a `.github/egress-firewall.yaml` of the wrong shape as one problem of the set-up and goes on with the other checks, where it ended with a Python traceback before: an empty file, a list in place of the mapping of the template, `allow` with a single host in place of a list, and an item of `allow` that is no host name, such as a number or a mapping. A host given as a string after `allow:` is no longer read letter by letter. The job event of a run on a runner with Harden-Runner names such a policy with the same lines.
