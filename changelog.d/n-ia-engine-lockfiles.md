### Security

- Gemini and Copilot now run exactly the packages that were checked. `analyze` installed the Gemini CLI and the Copilot CLI with `npm install` at a pinned version, so npm picked every package below them anew in each run, with the engine's secret in the job: a broken or malicious release of one of their dependencies would have reached every repository at once. Now the issue assistant ships a lock file for each, in `engines/`, with the SHA-512 hash of every package, and `analyze` installs it with `npm ci`, which refuses a package with another hash and stops the analysis before anything of it runs. npm runs in a folder of its own, without the scripts of the packages and without the engine's secret. The check *engine contracts* verifies the signature of npm's registry and the attestations of every package of the lock files whenever they change and every week, and that npm refuses another hash. Renovate keeps the lock files current, and its updates wait for the maintainer. The input `engine-version` of the action is gone, since the lock file names the version; a workflow of your own that still passes it gets a warning from GitHub and runs the locked version.
