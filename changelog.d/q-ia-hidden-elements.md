### Bug fixes

- The AI no longer reads the content of a `<video>` or of an `<rp>`, the brackets of ruby, which GitHub keeps but no browser shows: their text, and also paragraphs, headings, lists, links and images inside them, up to where GitHub ends the element, such as at its end tag in the same paragraph, or at the end of the paragraph or of the text where no end tag counts. A link or an image inside such an element no longer counts as an attachment. The text of a `<ruby>`, what follows the end tag, such a tag in code and the content of a `<details>` still reach the AI, as GitHub shows them.
- A tag on one row with a `>` in a quoted value, such as `<span data-x=">words">`, now goes whole, as GitHub hides it, in a paragraph, an HTML block, a quote, a list item and a cell of a table: the AI no longer reads the rest of the value. So do a few tags over rows that GitHub hides with what follows them, such as one right after `<?>`, one in a lazy row below an HTML block of a quote, and one after markup that ends on its row of a list item.
- Where GitHub hides the rest of a text, such as after a `<!--` without its `-->` in an HTML block, the AI no longer reads its footnotes, which GitHub shows after the end of the text and hides with it.
