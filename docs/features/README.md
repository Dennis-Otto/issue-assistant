# Features

Every feature of the issue assistant has a page of its own, which opens with a picture of how it works. [How it works](../how-it-works.md) shows how the workflows fit together, and [Configuration](../configuration.md) has every setting.

- **[The first analysis](first-analysis.md):** the likely cause with links to the code, what to try and what is missing, in the reporter's language.
- **[The life of an issue](life-of-an-issue.md):** labels say where an issue stands, and the assistant keeps what its comments promise, without AI.
- **[Priorities, owners and issue types](priorities.md):** an analysis can set a priority, assign an area's owners and follow the kind with an issue type.
- **[Waiting periods, exemptions and old threads](waiting-periods.md):** a reminder after 15 days and the closing after 30, or your own days, with exemptions and locks.
- **[Duplicates](duplicates.md):** a sure duplicate closes three days after its notice unless someone objects; others are suggestions.
- **[Related repositories](related-repositories.md):** also searches the issues of projects that share your users, and says when an issue may belong there.
- **[Questions in Discussions](discussions.md):** a first answer to a new question, with the same AI and the same checks, never marked as the answer.
- **[Slash commands](slash-commands.md):** steer the assistant from the issue, such as `/assistant again` or `/assistant ask <question>`.
- **[From the fix to the release](fix-to-release.md):** a fixed issue stays open until a release ships the fix, then closes with a link to it.
- **[What the AI reads](what-the-ai-reads.md):** each task reads what it needs and no more, and a first analysis learns from the maintainers' corrections.
- **[Languages](languages.md):** fourteen catalogs for the reporters, and a folded summary for maintainers who don't read their language.
- **[Limits of the AI runs](limits.md):** no stranger can run up the bill: the runs that others than the maintainers start are limited.
- **[What one run may cost](cost.md):** each run stops at its turns and its dollars, and the summary of its job says what it cost.
- **[What the sweep tells the maintainers](digest.md):** every morning what waits on whom, if you want in a pinned issue, and once a month how well it did.
- **[Good first issue candidates](good-first-issues.md):** the digest names the issues that someone new could take; only a maintainer adds the label.
- **[When GitHub fails](github-failures.md):** a rate limit, a server error or an incident never changes what the assistant posts.
